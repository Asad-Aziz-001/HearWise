## 🌟 Overview

**HearWise** is an adaptive, game-based auditory listening practice platform designed to help users improve their listening skills through **11 AI-powered games**, **real-time TTS audio**, and **personalized recommendations**.

Built with **React.js** frontend and **Python Flask** backend, the system provides adaptive difficulty, dynamic content generation, comprehensive analytics, and detailed PDF reports — all inside a secure, authenticated environment.

> ⚠️ **Note:** This is a **practice tool**, not a clinical diagnosis for Auditory Processing Disorder (APD).

## 🎮 11 Adaptive Game Modes

| # | 🎮 Game | 📋 Description | 🎯 Skill |

## 💻 Installation & Setup

### 📋 Prerequisites

```bash
✅ Python 3.10+
✅ Node.js 18+
✅ npm
✅ Git
```

### 🔧 Step-by-Step Setup

**Step 1 — Clone Repository**
```bash
git clone https://github.com/Asad-Aziz-001/hearwise.git
cd hearwise
```

**Step 2 — Backend Setup**
```bash
cd backend

# Create virtual environment
python -m venv venv

# Activate (Windows)
venv\Scripts\activate
# Activate (Linux/Mac)
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run backend
python app.py
# 🌐 http://localhost:5000
```

**Step 3 — Frontend Setup**
```bash
# New terminal
cd frontend

# Install dependencies
npm install

# Run frontend
npm start
# 🌐 http://localhost:3000
```

**Step 4 — Login**
```
👤 Demo User:  user@hearwise.com  /  user123
👑 Admin User:  admin@hearwise.com  /  admin123
```

## 🔄 How It Works

```
┌─────────────────────────────────────────────────────────┐
│  1. User logs in → JWT token issued                    │
│  2. Selects a game → Backend generates content via AI  │
│  3. Audio generated on-the-fly (gTTS)                  │
│  4. User answers → Auto-tested                         │
│  5. Performance recorded (accuracy + RT + errors)       │
│  6. Adaptive engine adjusts difficulty                 │
│  7. Dashboard shows updated progress                   │
└─────────────────────────────────────────────────────────┘
```
